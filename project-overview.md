# MoneyTrack — Project Overview

## Purpose

MoneyTrack is a command-line personal finance application that helps users
manage their income, expenses, accounts, categories, and budgets.

## Goal

The goal of MoneyTrack is to provide users with a simple way to record,
organize, search, and analyze their financial activity.

## Core Features

- Account management
- Income tracking
- Expense tracking
- Category management
- Budget management
- Transaction searching and filtering
- Monthly financial summaries
- SQLite data persistence

## Technology

- Python
- SQLite
- Object-Oriented Programming
- SQL
- Command-Line Interface
